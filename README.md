# EntrenaEnCasa

Rutinas de ejercicio para hacer en casa, pensadas para personas mayores: un maniquí de madera en 3D enseña cada ejercicio, las rutinas se guardan en el móvil, el entreno se apunta serie a serie (kg, repeticiones y descanso) y queda un historial.

- Web: https://franmv4.github.io/entrenaencasa/
- Se instala como app (Android: botón «Instalar»; iPhone/iPad: Compartir → «Añadir a pantalla de inicio») y funciona sin conexión.
- Un solo `index.html` sin dependencias propias (Three.js desde CDN). Los datos viven solo en el navegador de cada persona.
